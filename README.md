Jarvis es un asistente personal virtual en desarrollo, creado en Python.

## Actualmente puede:
- Responder a comandos escritos.
- Saludar e interactuar con el usuario.
- Indicar la hora actual.
- Recordar información temporalmente mediante un diccionario.
- Responder a comandos específicos.

## Tecnologías
- Python
- datetime

## Estado del proyecto
🚧 En desarrollo.

Este proyecto comenzó como un experimento para aprender programación y desarrollar progresivamente un asistente personal con nuevas capacidades.

**El objetivo:** construir un asistente inteligente, conectado a Internet y capaz de interactuar con distintos dispositivos y servicios.
